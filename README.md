# Floor-SEO

木地板（wood flooring）台灣 SEO 每週研究資料庫。由排程 agent 每週自動整理，涵蓋關鍵字、競品排名、內容題材與新聞趨勢四大主題。

## 資料夾結構

- `01-keywords-關鍵字研究/`：每週關鍵字清單與熱度推估（依主題分類：材質、風格、價格、安裝、保養等）
- `02-ranking-競品排名/`：核心關鍵字的 Google 搜尋結果觀察，含競品標題／內容特色與週間排名變化追蹤
- `03-content-內容題材/`：依當週關鍵字研究提出的部落格文章題目與大綱建議
- `04-news-新聞趨勢/`：過去 7 天內與木地板、建材、裝潢趨勢相關的新聞彙整

每個資料夾內的檔案以 `YYYY-MM-DD.md`（該週執行日期，UTC）命名，過去日期的檔案不會被竄改或刪除，只會持續新增當週檔案。

## 資料限制說明

本研究僅使用 WebSearch/WebFetch 等公開網路搜尋工具，**未使用 Ahrefs、SEMrush 等付費 SEO 工具**，因此關鍵字熱度、排名位置等數據皆為依搜尋結果趨勢的**推估值**，非精確流量或排名數據，僅供內容規劃參考。各檔案內皆有詳細的資料來源與限制說明。
